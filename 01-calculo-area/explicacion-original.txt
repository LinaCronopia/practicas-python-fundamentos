ALGORITMOS II - PRÁCTICA

------------------------------------------------------------------------------------
Problemática:
El usuario  quiere saber cuál es el área de un círculo teniendo su radio
------------------------------------------------------------------------------------

Algoritmo:
1. Solicitar al usuario que ingrese el radio del círculo
2. Calcular el área del círculo utilizando la fórmula: area = π * radio^2
3. Mostrar al usuario el área calculada
------------------------------------------------------------------------------------

Pseudocódigo:

Inicio

 Paso 1: Solicita al usuario el radio del círculo a Calcular
            Mostrar mensaje: "Por favor, ingrese el radio del círculo
            Leer el dato ingresado y asignarlo a la variable radio de tipo flotante

 Paso 2: Calcular el área del círculo utilizando la fórmula: area = π * radio^2
            Definir y asignar a la variable area el resultado

 Paso 3: Mostrar al usuario el área calculada
            Mostrar mensaje: "El área del circculo con radio ", radio, "es: ", area

Fin
