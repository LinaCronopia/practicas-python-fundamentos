# Prácticas de fundamentos de Python

Colección de ejercicios realizados durante mi formación inicial en Python. El repositorio reúne prácticas breves que originalmente estaban publicadas por separado y permite observar una progresión desde operaciones y condicionales hasta bucles y juegos de consola.

## Contenido

| Carpeta | Conceptos principales |
|---|---|
| `01-calculo-area` | Variables, entrada de datos, operaciones y módulo `math` |
| `02-centimetros-a-pulgadas` | Conversión de unidades y números decimales |
| `03-conversion-moneda` | Condicionales y validación de opciones |
| `04-control-de-edad` | Estructuras `if/else` |
| `05-juego-adivinanza` | Números aleatorios, bucles y control de intentos |
| `06-piedra-papel-tijeras` | Condicionales compuestos, bucles y puntuación |

Los primeros cuatro ejercicios conservan también sus explicaciones y diagramas de flujo originales.

## Cómo ejecutar los ejercicios

Se necesita Python 3. Desde la raíz del repositorio, por ejemplo:

```bash
python 01-calculo-area/calculo_area.py
```

Cada ejercicio funciona de manera independiente y no requiere instalar dependencias externas.

## Alcance

Son prácticas formativas de consola. Al consolidarlas se corrigieron errores tipográficos, se agregaron validaciones básicas y se normalizaron los nombres de archivos, manteniendo el propósito original de cada ejercicio.
